14. 答案 CD　【定位】第1章 计算机硬件基础, 1.3 数据在计算机内的表示与处理, 知识点2 计算机中常见的信息编码。 【解析】选项 A：将汉字的区位码直接加上 2020H 就是国标码 → 错误 错误点在于 “直接加” 忽略了区位码的进制转换，正确步骤为： 区位码是 “区码 + 位码” 的十进制组合（如某汉字区位码为 1601，区码 16、位码 01 均为十进制）； 需先将区码、位码分别转换为十六进制（如 16→10H，01→01H）； 再将十六进制的区码、位码分别加 20H（合为 2020H），得到国标码（如 1001H + 2020H = 3021H）。 直接用十进制区位码加十六进制 2020H，数值逻辑错误，因此 A 错误。 选项 B：ASCII 使用了 8 位二进制对西文字符进行编码 → 错误 ASCII 码分两类： 基本 ASCII 码（核心）：仅用 7 位二进制，可表示 128 个字符（0-127，涵盖字母、数字、符号），最高位固定为 0； 扩展 ASCII 码：在 7 位基础上加 1 位最高位（可设为 1），用于表示更多特殊字符，但并非所有 ASCII 编码都依赖 8 位，且 “标准 ASCII” 的定义以 7 位为核心。 选项 B 未区分 “基本” 与 “扩展”，表述不准确，因此 B 错误。 选项 C：将 16 进制国标码加上 8080H 就是机内码 → 正确 这是汉字编码的标准转换规则，核心目的是 “区分汉字与 ASCII 码”： 国标码的高、低字节最高位均为 0（如国标码 3021H，二进制为 00110000 00100001），与 ASCII 码（最高位 0）无法区分； 为解决冲突，将国标码的高、低字节分别加 80H（十六进制），合起来即加 8080H，得到机内码（如 3021H + 8080H = B0A1H，二进制为 10110000 10100001）； 机内码最高位为 1，可与 ASCII 码明确区分，因此 C 正确。 选项 D：存储一个 16*16 点阵的汉字需要 32 个字节 → 正确 计算逻辑基于 “点阵像素与字节的换算”： 16×16 点阵的汉字，总像素点 = 16 × 16 = 256 个； 每个像素点用 1 位二进制表示（0 = 暗，1 = 亮），因此共需 256 位存储； 因 1 字节 = 8 位，总字节数 = 256 位 ÷ 8 = 32 字节。 计算结果完全正确，因此 D 正确。 因此，正确选项是 CD。

23. 答案 BCD　【定位】第4章 信息安全技术, 4.5 信息安全相关法规, 知识点1 信息安全相关法规。 【解析】选项 A：关系国家安全和利益 关键区别性：这是国家秘密与其他所有秘密的根本差异。 商业秘密仅关系 “企业经济利益”（如技术配方、客户数据），不涉及国家安全； 个人隐私秘密仅关系 “个人权益”（如私人通讯、健康信息），与国家安全无关； 只有国家秘密直接关联 “国家安全和利益”（如国防战略、军事部署、核心科技），一旦泄露可能危害国家主权、领土完整或公共安全。 选项 B：依照法定程序确定 非关键区别性：“法定程序” 并非国家秘密独有。 商业秘密的确定需遵循企业内部程序（如保密制度、员工保密协议），或《反不正当竞争法》等法律程序； 选项 C：在一定时间内保密 非关键区别性：“时间性” 是所有秘密的共性，而非国家秘密独有。 国家秘密有明确保密期限（如绝密级不超过 30 年），到期后解密； 选项 D：只限一定范围的人员知悉 非关键区别性：“限制知悉范围” 是 “秘密” 的基本属性（无范围限制则不成为 “秘密”），并非国家秘密独有。 商业秘密只限企业核心员工（如技术研发人员、高管）知悉； 因此，国家秘密区别于其他秘密的唯一关键是 “关系国家安全和利益”，而B.C.D 是所有秘密的共性特征，不是关键区别。

38. 答案 AC　【定位】第3章 网络技术基础, 3.3 计算机网络的组成与应用, 知识点2 局域网技术 【解析】选项 A：交换机 - 数据链路层 交换机的核心功能是根据 MAC 地址转发数据帧，通过维护 MAC 地址表实现局域网内设备的直接通信，处理的是 “帧” 级别的数据单元，对应 OSI 的数据链路层。A 正确。 选项 B：路由器 - 传输层 路由器的核心功能是根据 IP 地址进行跨网络路由选择，处理的是 “数据包” 级别的数据单元（包含 IP 地址），对应 OSI 的网络层，而非传输层。B 错误。 选项 C：modem - 物理层 Modem（调制解调器）的核心功能是实现数字信号与模拟信号的转换（如将电脑的数字信号转为电话线可传输的模拟信号），仅处理物理层的 “比特流” 信号，对应 OSI 的物理层。C 正确。 选项 D：网关 - 网络层 网关的核心功能是连接不同体系结构的网络（如 TCP/IP 与其他协议网络），需处理高层协议转换（通常涉及应用层及以上），而非仅工作在网络层。D 错误。 综上，正确答案为 AC。
